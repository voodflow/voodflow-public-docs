# Voodflow

**Voodflow** is a self-hosted **visual workflow automation** plugin for **Laravel** and **Filament**. You design automations in a drag-and-drop editor inside your admin panel: triggers, branching logic, HTTP requests, webhooks, notifications, and more. Workflows run on your own stack—credentials and execution data stay in **your** infrastructure (no third-party automation cloud required for core operation).

It is built for **Filament v4** (Livewire), supports **custom PHP nodes**, **JSON import/export** of workflows, **detailed execution logs**, and integrations such as **inbound/outbound webhooks** and **HTTP-based AI/LLM** calls.
